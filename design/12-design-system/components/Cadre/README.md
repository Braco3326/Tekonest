# Cadre

A frame taken from the nested frames of Damascene inlay boxes: a `noyer` border plus an inner filet offset 7px, and one `ambre` triangle in the top-left and bottom-right corners (the mother-of-pearl corner pieces). Use for the three entrance cards and other key blocks — never on every element. Square corners (`radius-0`). The consumer provides the content; keep 24px (`space-6`) inner padding.
