# Medaillon

The 12-point star {12/5} at the heart of Damascene inlay boxes, drawn as a single hairline with an outer circle and offset dodecagon. One large medallion per page, behind the nest in the hero; a 16–18px solid star may replace list bullets (`prune` on Papier, `ambre` on Nuit). Never filled, never more than one large one in view.
