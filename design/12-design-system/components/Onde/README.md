# Onde

The Damascus-steel wave: many thin layered lines folded by a few slow sine fields, like forged steel or a sound wave seen from above. A background texture for the hero and posters, tone-on-tone (`noyer` with a few `ambre` lines on Nuit). Never behind running text; keep it under 25% contrast with the ground. Slow drift only, and static under `prefers-reduced-motion`.
