# 09 — Logo: le nid tressé (L4)

Chosen by the founder on 24 Oct 2026, as drawn ("as it is: same colours, same everything").

- **Idea:** tek (technician) + nest. Seven rotated ellipses weave a nest; each line is one person / one cable of the network.
- **Inspiration:** a hand-drawn nest seen from above and Monique Goossens' hair-typography "O" (founder's Pinterest references; used for mood only, nothing copied).
- **Font:** Tektur Medium (SIL OFL, `Tektur-OFL.txt`); text is outlined in the SVGs.
- **Colours:** ink `#141414` on paper `#F4F1EA` (provisional; colour pass pending).
