TekPractice, le simulateur de câblage

Un simulateur 3D dans le navigateur. Vous choisissez un lieu, vous y posez du vrai matériel son, vous le câblez. Quand un branchement est impossible, TekPractice vous dit pourquoi.

Jouer maintenant

Fonctionne dans un navigateur récent sur ordinateur (écran 1366 × 768 ou plus). Vos montages et essais restent dans votre navigateur.

Version d'essai

Mode Création : installez, câblez, écoutez

TekPractice s'ouvre sur le Mode Création. Vous montez une sono dans un lieu, pas à pas, et vous voyez ce qui marche.

  1. Choisissez un lieu. 36 lieux : 32 salles et espaces (studios, théâtres, églises, scènes en plein air…), 3 décors et une salle vide neutre. Tous s'ouvrent vides ; cinq salles s'ouvrent aussi avec leur matériel.
  2. Posez du vrai matériel. Console, micros, enceintes amplifiées et une multiprise générique : des modèles de matériel réel (marques et références existantes), simplifiés, choisis dans l'inventaire.
  3. Câblez. Reliez une prise à une autre. Si le branchement est impossible (mauvais connecteur, mauvais type de signal, mauvais sens), TekPractice le refuse et vous dit pourquoi, en français. Cinq autres règles signalent une erreur ou un avertissement une fois le câble posé : alimentation fantôme, voyant ON-AIR, coupure des écoutes, retour N-1, word clock.
  4. Écoutez. Quand le signal arrive aux enceintes, lancez le signal de test ou choisissez votre propre fichier audio (MP3, WAV ou OGG), depuis la Régie, le Premier rang ou le Fond de salle (selon le lieu). C'est une simulation simple : niveau, retard et placement gauche-droite d'après la géométrie, sans acoustique de salle. Votre fichier reste dans votre navigateur : il n'est ni envoyé ni enregistré. Aucun morceau n'est fourni.
  5. Voyez la couverture. Des points de couleur montrent les niveaux relatifs dans la salle, le point le plus fort de la grille valant 0 dB. C'est une estimation pédagogique : les niveaux sont comparés entre eux, pas mesurés. Son direct seulement, sans les réflexions de la salle.

Les raccourcis

Les raccourcis clavier du Mode Création sont dans le menu Aide, dans le jeu : Aide, puis Raccourcis clavier. Les touches ne fonctionnent pas quand vous écrivez dans un champ.
